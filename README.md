Student Exam Performance Analysis

 Project Overview

This project focuses on analyzing student exam performance using Python and Exploratory Data Analysis (EDA) techniques.

The analysis is performed on a student exam dataset containing information about students' gender, ethnic group, parental education, parental marital status, study habits, and academic scores.

The main purpose of this project is to understand the distribution of students and identify relationships between different background factors and their performance in Math, Reading, and Writing.

Through data cleaning, descriptive statistics, grouping, and visualization, the project provides a clear overview of the factors associated with student academic performance.

 Project Objectives

Analyze the distribution of students by gender.

Explore the distribution of students across different ethnic groups.

Examine the relationship between parental education and student scores.

Analyze student scores based on parental marital status.

Understand the distribution of Math, Reading, and Writing scores.

Perform basic data-quality checks using Pandas.

Present the findings using clear and meaningful visualizations.

 Analysis Performed

1. Student Gender Distribution

A count plot was used to understand the distribution of students across different gender categories.

The chart includes value labels on the bars, making the comparison easier to understand.

2. Parental Education and Student Performance

A grouped analysis was performed using parental education and the mean scores of:

Math

Reading

Writing

A heatmap was then used to visualize the relationship between parental education and average student performance.

3. Parent Marital Status and Student Scores

Student scores were grouped according to Parent Marital Status.

The average Math, Reading, and Writing scores were visualized using a heatmap to make differences between categories easier to compare.

4. Distribution of Student Scores

Boxplots were created separately for:

Math Score

Reading Score

Writing Score

These visualizations help understand the central distribution, spread, and possible variation in student scores.

5. Ethnic Group Distribution

The number of students in each ethnic group was calculated and represented through a pie chart.

The chart displays the percentage contribution of each ethnic group to the overall dataset.

 Conclusion

This project demonstrates how Exploratory Data Analysis can be used to examine student performance data and identify meaningful patterns.

Using Pandas for data analysis and Matplotlib and Seaborn for visualization, the project transforms raw student data into understandable charts and summaries.

The analysis provides an overall view of student demographics, parental background, and academic score distributions. These findings can be used as a starting point for deeper statistical analysis or predictive modeling of student performance.
